# Support

## Getting Help

1. 📖 Read the [README.md](README.md) for local dev setup and endpoints
2. 🔍 Check [MASTER_INDEX.md](MASTER_INDEX.md) for this repo's documentation map
3. 📚 For platform-wide standards, see
   [CloudForge-Platform-Foundation](https://github.com/CloudForge-Platform-Foundation-dev/CloudForge-Platform-Foundation)
4. 🐛 For bugs specific to Ingest Studio, open a GitHub Issue in this repo

## Scope

This repository covers **Ingest Studio only** (CSV/JSON/Excel parsing, AI Guard, mapping).
For issues with other Studios (Knowledge, Nova, Security, Compliance) or with platform-wide
governance rules, open an issue in the relevant repository instead.
